# Raindrop同期のレート制限

## 目的

Raindropのタグ・ノート同期をAPI制限内で実行し、通常のブックマーク生成は遅くしない。

## 挙動

`sync_request_interval_seconds` を設定項目として追加し、既定値を `0.5` 秒にする。`--sync-raindrop-tags` と `--sync-raindrop-summary` で発行する各Raindrop HTTPリクエストの開始間隔だけを制限する。他のコマンドには適用しない。

RaindropがHTTP 429を返した場合、`Retry-After` と `X-RateLimit-Reset` のうち遅い時刻まで待ち、短い安全余裕を加えて再試行する。リセット時刻ヘッダーはUTCのepoch秒である。その他の一時エラーに対する再試行は従来どおりとする。

## 観測性

両方の同期コマンドは既存の最終行 `elapsed=<秒>s` を維持し、開始時には設定されたリクエスト間隔を表示する。最終行では予定・更新・スキップ・失敗・経過時間を確認できる。

## 検証

設定値の検証、有効時だけのリクエスト間隔、リセット時刻ヘッダーによる再試行待機、同期開始時の表示、既存の経過時間表示をテストする。
