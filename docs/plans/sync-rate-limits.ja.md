# Raindrop同期のレート制限 実装計画

**目的:** 同期リクエストだけを0.5秒間隔にし、HTTP 429時はサーバーのリセット時刻まで待つ。

- [ ] `sync_request_interval_seconds` を既定値0.5秒で追加し、同期用Raindropクライアントだけへ渡す。
- [ ] クライアント内で各HTTPリクエスト開始前に単調時計で間隔を制御する。
- [ ] `Retry-After` と `X-RateLimit-Reset` を比較し、遅い方まで安全余裕つきで待つ。
- [ ] 両同期コマンドの開始時に間隔を表示し、既存の最終 `elapsed` 表示を維持する。
